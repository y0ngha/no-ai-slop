# 알림 문구 운영 인계 일정안

알림 문구 운영 업무가 여러 팀의 접점에 놓여 있다는 점을 고려하면 이번 인계는 파일 전달 이상의 정리 과정을 필요로 합니다. 그동안 제품운영팀에서 문구 수정 요청을 취합했으며, 다음 달부터는 고객경험팀이 이 창구를 맡습니다. 원활한 전환이라는 공동의 목적을 위해 일정을 공유합니다. 실제 담당 창구가 바뀌는 시점은 2026년 11월 2일 오전 10시이며 모든 시간은 한국 표준시(KST)입니다.

이번 범위는 한국어 웹 알림 18개의 문구 수정 요청 접수와 승인 이력 관리입니다. 앱 푸시, 이메일, 번역 문구는 포함하지 않습니다. 고객경험팀이 문구를 직접 배포하는 권한까지 받는 것도 아닙니다. 배포는 계속 웹개발팀이 담당하고 최종 문구 승인은 제품기획팀이 맡습니다. 접수와 승인은 별도 책임입니다.

제품운영팀 이서진은 10월 23일 오후 3시까지 18개 문구 목록, 최근 승인 이력, 열려 있는 요청을 공유 폴더에 올립니다. 목록에는 문구 식별자와 노출 위치가 모두 있어야 합니다. 고객경험팀 박민서는 10월 26일 오후 5시까지 파일을 열 수 있는지와 식별자 누락 여부를 확인합니다. 과거 문구를 재심사하지 않고 자료의 사용 가능 여부만 확인합니다. 누락이 있으면 박민서가 같은 날 목록에 표시하고 이서진이 10월 27일 정오까지 보완합니다.

접수에 쓸 요청 양식은 제품기획팀 정하린이 10월 27일 오후 3시까지 확정합니다. 필수 항목은 문구 식별자, 바꾸려는 이유, 원하는 적용일 세 가지입니다. 원하는 적용일을 적었다고 그날 배포가 약속되는 것은 아닙니다. 웹개발팀 오준호는 확정된 양식을 받은 뒤 10월 28일 오후 5시까지 시험 요청 한 건이 승인 대기 목록에 들어오는지 확인합니다. 이 시험에는 실제 사용자에게 보이는 문구 변경을 넣지 않습니다.

합동 연습은 10월 29일 오후 2시부터 2시 30분까지입니다. 박민서가 요청을 접수하고 정하린이 승인 또는 반려를 기록하며 오준호가 배포 요청을 받는 곳까지 따라가 봅니다. 이서진은 연습 중 질문을 모으고 당일 오후 5시까지 안내문을 수정합니다. 참석자가 한 명이라도 어렵다면 연습 완료로 간주하지 않고 박민서가 대체 시간을 조율합니다. 녹화 시청으로 대체하지는 않습니다.

전환 여부는 10월 30일 오후 3시에 정하린이 결정합니다. 자료 확인, 양식 확정, 시험 요청, 합동 연습이 모두 끝나야 전환할 수 있습니다. 한 항목이라도 남으면 창구 변경을 미루고 제품운영팀이 기존 접수를 이어 갑니다. 이 경우 새 전환일은 정하린이 관련 팀과 협의해 10월 30일 오후 5시까지 공지합니다. 대체 날짜는 아직 미정입니다.

전환 시점 전에 들어온 요청은 완료될 때까지 이서진이 맡고, 전환 시점부터 들어온 요청은 박민서가 맡습니다. 중복 접수가 발견되면 먼저 접수된 요청 하나를 남기고 그 요청의 담당자가 진행합니다. 내용이 같은지 판단하기 어렵다면 두 담당자가 먼저 확인한 뒤 합칩니다. 11월 6일 오후 4시에 남은 요청을 함께 확인하되 그날이 기존 요청의 강제 종료일은 아닙니다.

일정 준수를 위해 특히 필요한 것은 자료 접근 권한과 양식 확정입니다. 권한이 막히면 박민서가 이서진에게 알리고 이서진이 사내 도구 관리자에게 해제를 요청합니다. 양식이 늦으면 오준호의 시험도 시작할 수 없습니다. 각 담당자는 자기 단계가 늦어질 것으로 보이는 즉시 정하린에게 예상 완료 시간을 공유해 주세요. 현재는 모든 단계가 기한 안에 끝난다는 전제로 잡은 계획이며, 완료됐다는 보고는 아닙니다.
