# 보관함 권한 변경 안내와 확인 요청

보관함을 함께 이용하는 과정에서 역할의 명확성을 높이기 위한 권한 변경이 예정되어 있어 공유드립니다. 먼저 이번 변경으로 기존 문서가 지워지거나 공개 범위가 넓어지는 것은 아닙니다. 달라지는 것은 누가 보관함 밖으로 파일을 내려받을 수 있는지입니다.

2026년 10월 20일 오전 10시 KST부터 ‘열람자’는 화면에서 문서를 읽을 수 있지만 다운로드는 할 수 없습니다. ‘편집자’는 읽기, 내용 수정, 다운로드가 가능하며 다른 사람의 역할을 바꿀 수 없습니다. ‘관리자’는 편집자의 기능에 더해 초대와 역할 변경을 할 수 있습니다. 관리자도 문서의 작성자를 바꾸는 기능은 없습니다. 현재 역할은 그대로 유지되고, 역할별 기능만 위와 같이 바뀝니다.

이미 내려받은 파일을 회수하는 기능은 없으며 기존 공유 링크로 접속해도 로그인한 사람의 역할을 적용합니다. 이 조치가 외부 복사를 모두 막는다는 의미는 아닙니다. 화면 내용을 따로 옮길 가능성은 남아 있다는 설명을 같이 드립니다.

지수님은 운영팀 담당자로서 현재 열람자 중 업무상 다운로드가 필요한 사람과 이유를 10월 16일 오후 2시 KST까지 권한 검토표에 적어 주세요. 적힌 사람을 자동 승격하지 않고 관리자 윤서님이 검토합니다. 대상이 없으면 ‘해당 없음’을 남겨 주세요. 기한 내 파악이 어려우면 같은 시각까지 예상 완료일을 알려 주시면 됩니다. 확인이 늦어도 변경 일정은 유지되며, 그동안 열람자는 다운로드할 수 없습니다.
