# 보관함 권한 변경 안내와 확인 요청

2026년 10월 20일 오전 10시 KST부터 보관함의 역할별 기능이 바뀝니다. 현재 역할은 그대로 유지됩니다. 기존 문서가 지워지거나 공개 범위가 넓어지는 것은 아니며, 달라지는 것은 누가 보관함 밖으로 파일을 내려받을 수 있는지입니다.

- ‘열람자’는 화면에서 문서를 읽을 수 있지만 다운로드는 할 수 없습니다.
- ‘편집자’는 읽기, 내용 수정, 다운로드가 가능하며 다른 사람의 역할을 바꿀 수 없습니다.
- ‘관리자’는 편집자의 기능에 더해 초대와 역할 변경을 할 수 있습니다. 관리자도 문서의 작성자를 바꿀 수는 없습니다.

이미 내려받은 파일을 회수하는 기능은 없습니다. 기존 공유 링크로 접속해도 로그인한 사람의 역할이 적용됩니다. 다만 화면 내용을 따로 옮길 수는 있으므로, 이번 변경으로 외부 복사를 모두 막을 수 있는 것은 아닙니다.

지수님, 운영팀 담당자로서 현재 열람자 중 업무상 다운로드가 필요한 사람과 그 이유를 10월 16일 오후 2시 KST까지 권한 검토표에 적어 주세요. 적힌 사람은 관리자 윤서님이 검토하며, 자동으로 역할이 올라가지는 않습니다. 대상이 없으면 ‘해당 없음’을 남겨 주세요.

기한 내 파악이 어려우면 같은 시각까지 예상 완료일을 알려 주세요. 확인이 늦어도 권한은 예정대로 변경됩니다. 변경 후에도 열람자로 남아 있는 동안에는 다운로드할 수 없습니다.
